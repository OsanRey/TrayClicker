# Кликер в трее

Компактный кликер для Windows 10 1803+/11 x64. Интерфейс на русском, окно настроек 312 × 278 пикселей при масштабе 100%. Установки не требуется.

## Запуск

Запустите **dist/TrayClicker.exe**. Выберите настройки и нажмите **«Сохранить и в трей»**.
Готовая программа доступна в [Releases](https://github.com/OsanRey/TrayClicker/releases/latest).
Для запуска потребуется [.NET Desktop Runtime 8 x64](https://dotnet.microsoft.com/download/dotnet/8.0).

## Настройки

- **Левая / правая кнопка:** включите одну или обе. У каждой своя скорость от 0,1 до 500 кликов в секунду.
- **Режим «Заданное число кликов»:** при активной горячей клавише физическое нажатие выбранной кнопки мыши запускает серию из 1–1 000 000 кликов этой кнопкой. Удержание мыши не повторяет серию. Чтобы запустить следующую, нажмите кнопку мыши снова. Повторное нажатие во время незавершённой серии игнорируется.
- **Режим «Пока держу кнопку мыши»:** клики идут только при одновременном разрешении горячей клавишей и физическом удержании выбранной кнопки мыши. Отпустили мышь — клики прекратились; зажали снова — возобновились. Поле количества в этом режиме отключено.
- **Горячая клавиша:** по умолчанию F6. Нажмите кнопку смены клавиши, затем нужную клавишу или боковую кнопку мыши X1/X2. Для смены уже выбранной боковой кнопки нажмите «Мышь X1» или «Мышь X2». Поддерживаются буквы, цифры, F-клавиши и другие обычные клавиши. Esc зарезервирован для остановки; Ctrl, Alt, Shift и Win не используются как клавиша запуска.
- **Клавиша → «Удерживать»:** разрешение действует, пока горячая клавиша зажата. Отпускание клавиши останавливает клики, в том числе незавершённую серию.
- **Клавиша → «Вкл / выкл»:** первое нажатие разрешает обработку мыши, следующее запрещает. Отпускание клавиши и её автоповтор не переключают состояние. Достигнутое количество заканчивает только текущую серию; разрешение остаётся включённым.

В режимах заданного количества и удержания мыши сама горячая клавиша не запускает клики. Нажатие левой кнопки запускает только левые клики; правой — только правые. Если включены и удерживаются обе, они работают независимо; при совпадении времени сначала отправляется левый клик, затем правый.

В режимах заданного количества и удержания мыши при активной горячей клавише исходное физическое нажатие выбранной кнопки заменяется программными кликами. Поэтому количество в серии — **ровно N, а не N + обычный щелчок**. Когда горячая клавиша не активна, мышь работает как обычно. Первый программный клик происходит сразу после обработки нажатия.

## Управление

- **Esc** останавливает клики в любом режиме.
- Клики отправляются в **текущую позицию курсора**. Горячая клавиша действует глобально и не блокируется для других программ.
- Левый щелчок по значку в трее открывает настройки. При открытии настроек или меню трея текущий запуск останавливается. После закрытия нужен новый запуск горячей клавишей.
- Правый щелчок открывает меню: настройки, разрешение горячей клавиши, остановка, счётчики и выход.
- Значок: синий — готов, зелёный — кликает, серый — настройки открыты или горячая клавиша отключена.
- Закрытие окна или сворачивание сохраняет настройки и прячет окно в трей. Чтобы полностью закрыть программу, выберите **«Выход»** в меню трея.
- Настройки хранятся в `settings.json` **рядом с .exe**. Папка должна разрешать запись. Чтобы перенести программу с настройками, скопируйте оба файла.

Заданная скорость — целевая частота. Используется таймер Windows высокой точности, который не зависит от обычного ожидания потока в скрытом окне трея. Планировщик сохраняет временную сетку между кликами и не накапливает небольшие задержки пробуждения. Большие пропущенные интервалы не компенсируются пачкой кликов. Нажатие и отпускание кнопки мыши отправляются парой.

Версия 1.0.1 проверена на реальных кликах Windows в отдельном принимающем окне: при настройке 52 получено 52,43 клика/с; при 202 — 202,68; при 500 — 499,12. Правая кнопка при 202 дала 202,69. Одновременно левая при 202 и правая при 500 дали 202,55 и 496,90 соответственно. Каждый замер длился около 2 секунд; все отправленные клики были получены. Конкретное приложение или сайт может обрабатывать события с другой скоростью.
Для управления программой, работающей от администратора, кликеру нужны те же права — это [ограничение Windows SendInput](https://learn.microsoft.com/windows/win32/api/winuser/nf-winuser-sendinput).

## Сборка из исходников

Нужен Windows и .NET SDK 8 с Windows Desktop reference pack. В PowerShell:

```powershell
.\build.ps1
```

Сборка выполняется без сторонних NuGet-пакетов. Результат: `dist/TrayClicker.exe`, один файл с зависимостью от установленного .NET Desktop Runtime 8.

## Проверка

```powershell
.\dist\TrayClicker.exe --self-test "$PWD\verification\tests.txt"
.\dist\TrayClicker.exe --preview "$PWD\verification\settings-preview.png"
```

28 встроенных проверок проверяют разрешение горячей клавишей, запуск серий мышью, три режима, скорости, количество, остановку, замену физических щелчков, отсутствие накопления задержки, сохранение формата настроек и размер Windows INPUT. Эти проверки **не генерируют реальные клики**. Режим preview создаёт снимки обоих режимов окна без запуска кликера и без записи настроек.

`--smoke-test <путь-к-отчёту>` проверяет обычный запуск окна, трея, обработчика мыши и рабочего потока, затем корректно закрывает приложение. Клики при этом приостановлены. Непредвиденные ошибки запуска записываются в `error.log` рядом с программой.

`--benchmark <путь-к-отчёту>` запускает измерение реальной скорости через Windows SendInput в отдельном тестовом окне. Проверяются 52/202/500 для левой кнопки, 202 для правой и одновременные 202/500. Тест занимает примерно 12 секунд. Курсор временно устанавливается в тестовое окно и восстанавливается после завершения, если пользователь не перемещал его. Esc или выход курсора из окна останавливает проверку. Настройки кликера не меняются.


## Автоклик по активации

Третий режим запускает непрерывные клики выбранными кнопками мыши сразу при нажатии кнопки активации (клавиша или X1/X2). Повторное нажатие останавливает клики. Отпускание кнопки активации не останавливает работу; удерживать мышь не нужно. Esc, открытие настроек и меню трея также останавливают клики. Количество отключено, скорость каждой кнопки применяется. Поведение активации в этом режиме всегда «Вкл / выкл».
